# Chromospace

Website of the Chromospace art collection: trading cards, street art, prints, paintings and NFTs.

Live at https://chromospace.art

- `index.html`: the whole site (one page, no build step)
- NFTs load in the browser from the public Blockscout API for wallet `0xb884ad7ab6af74693fec7f364eb8bfb31fc7ecea`
- Physical works are listed in the `PHYSICAL` array inside `index.html` (currently placeholders)
